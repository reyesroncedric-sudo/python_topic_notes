# Python Notes: Structured Examples (Part 1)

Each topic has its own folder with 8 examples that get harder as the number goes up.

| Difficulty | Example numbers |
|---|---|
| Easy | ex01 to ex03 |
| Intermediate | ex04 to ex06 |
| Hard | ex07 to ex08 |

## Topics

| Folder | Topic |
|---|---|
| `01_list_basics/` | creating lists, indexing, slicing, add/remove, sorting, searching, copying, nested lists, matrices |
| `02_list_comprehension/` | loop vs comprehension, expressions, conditions, if-else, zip/enumerate, nested comprehensions |
| `03_string_methods/` | case, slicing, strip/replace, search, split/join, formatting, palindrome, cipher |

## How to run an example

```
python 01_list_basics/ex01_easy_creating_and_printing_lists.py
```

Every file has comments that explain the code and shows the expected output at the bottom.
